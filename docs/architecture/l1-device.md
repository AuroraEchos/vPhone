# L1 Device

设备层是 vPhone 与 Android 设备之间的同步、无业务语义边界。

## 职责

- 发现 ADB 设备并报告授权、离线等状态。
- 为一台已就绪设备创建会话；同一进程内访问同一设备的所有会话共享串行锁。
- 采集并验证 PNG 截图。
- 采集 UI Automator XML，并解析为只包含原始属性的节点列表。
- 提供点击、滑动、按键和受限 ASCII 文本输入原语。
- 为每个操作提供超时和稳定错误类型。

## 非职责

- 不查找或匹配语义元素。
- 不融合截图和控件树。
- 不选择动作，不维护任务状态。
- 不自动重放可能已经下发的输入命令。
- 不向上层暴露任意 ADB shell。

控件树节点 ID 只在所属快照内有效。密码节点的文本和内容描述在解析时清空。
