# L1 Device

设备层是 vPhone 与 Android 设备之间的同步、无业务语义边界。

## 职责

- 发现 ADB 设备并报告授权、离线等状态。
- 为一台已就绪设备创建会话；同一进程内访问同一设备的所有会话共享串行锁，跨进程采集使用唯一临时路径避免文件冲突。
- 采集并验证 PNG 截图。
- 采集 UI Automator XML，并解析为只包含原始属性的节点列表。
- 提供点击、滑动、按键和可打印 Unicode 文本输入原语。
- 为每个操作提供超时和稳定错误类型。

## 非职责

- 不查找或匹配语义元素。
- 不融合截图和控件树。
- 不选择动作，不维护任务状态。
- 不自动重放可能已经下发的输入命令。
- 不向上层暴露任意 ADB shell。

控件树节点 ID 只在所属快照内有效。密码节点的文本和内容描述在解析时清空。

ASCII 文本使用 Android 原生 `input text` 快速路径。非 ASCII 文本通过随包分发的最小
UI Automator helper，对当前聚焦的可编辑无障碍节点执行 `ACTION_SET_TEXT`；helper 仅临时
推送到设备，操作结束后删除，不安装应用、不使用剪贴板，也不更改用户输入法。控制字符
不属于文本输入能力。该 Unicode 路径要求 Android 5.0（API 21）或更高版本。
